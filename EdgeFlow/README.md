# EdgeFlow (Windows 虚拟桌面边缘切换工具)

**EdgeFlow** 是一个极其轻量级的 Windows C++ 工具。它允许你通过将鼠标移动到屏幕的最左侧或最右侧边缘并短暂停留，来快速切换 Windows 虚拟桌面。

无界面、无黑框、极低资源占用。

## ✨ 功能特性

*   **鼠标左边缘停留**：切换到 **上一个** 虚拟桌面 (模拟`Ctrl + Win + Left`).
*   **鼠标右边缘停留**：切换到 **下一个** 虚拟桌面 (模拟`Ctrl + Win + Right`).
*   **静默运行**：程序作为后台进程运行，没有控制台窗口。
*   **防误触**：支持自定义边缘停留时间（默认 300ms）。
*   **多屏支持**：自动识别扩展屏幕的最左和最右边界。
*   **安全退出**：长按屏幕**左上角**可安全退出程序。

## 🚀 使用方法

### 1. 基础运行
双击 `EdgeFlow.exe` 即可启动。默认触发延迟为 **300毫秒**。

### 2. 自定义延迟 (命令行)
如果你觉得切换太快（容易误触）或太慢，可以通过命令行参数启动：

```bash
# 设置为 200毫秒 (极速)
EdgeFlow.exe 200

# 设置为 800毫秒 (防误触)
EdgeFlow.exe 800
```

*也可以创建快捷方式，右键属性 -> 目标，在路径末尾添加数字参数。*

### 3. 开机自启
如果希望开机自动运行：
1. 按下 `Win + R`，输入 `shell:startup` 并回车。
2. 将 `EdgeFlow.exe` 的快捷方式放入打开的文件夹中。

## ❌ 如何退出程序

由于程序没有窗口，你可以通过以下两种方式退出：

1.  **手势退出（推荐）**：
    *   将鼠标移动到屏幕**最左上角**死角 (坐标 0,0)。
    *   保持不动 **3秒钟**。
    *   程序会弹出提示框确认退出。
2.  **任务管理器**：
    *   在任务管理器中找到 `EdgeFlow.exe` 并结束任务。

## ⚠️ 常见问题

*   **Q: 多显示器如何判定？**
    *   A: 程序识别的是整个虚拟桌面的最左和最右端。如果你有两个显示器横向排列，只有最左侧显示器的左边缘和最右侧显示器的右边缘有效，中间的连接处不会触发。
*   **Q: 程序打不开了？**
    *   A: 程序内置了单例检查。如果后台已经有一个 `EdgeFlow` 在运行，再次双击会提示“程序已在运行中”。请先检查任务栏或使用左上角退出法。
